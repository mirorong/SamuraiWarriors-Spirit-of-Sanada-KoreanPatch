# 전국무쌍 사나다마루 비공식 한글패치

스팀판 **전국무쌍 사나다마루 (SAMURAI WARRIORS: Spirit of Sanada)** 를 한국어로 즐길 수 있게 해 주는 비공식 한글패치입니다.

> 📖 **설치 방법, 스크린샷, 업데이트 소식은 블로그에서 확인하세요**
> 👉 https://mirorong0323.tistory.com/6

## 다운로드

[**최신 버전 받기**](https://github.com/mirorong/SamuraiWarriors-Spirit-of-Sanada-KoreanPatch/releases/latest)

Releases 페이지의 **Assets**에서 패치 zip 파일을 받으시면 됩니다.
함께 표시되는 Source code 파일은 받을 필요 없습니다.

## 설치

1. 게임을 종료합니다.
2. 스팀 라이브러리에서 게임을 우클릭 → **관리 → 로컬 파일 보기**로 게임 폴더를 엽니다.
3. 받은 zip의 `게임폴더에_복사` 폴더 안의 내용을 모두 게임 폴더에 복사합니다.
4. 게임 우클릭 → **속성 → 일반 → 언어**가 **English**인지 확인한 뒤 게임을 실행합니다.

**삭제:** 게임 폴더에서 `dinput8.dll`, `swskr_patch.bin`, `swskr.log`(있으면), `Data\LINKDATA_KOR_LANG.BIN`을 지우면 원래대로 돌아갑니다.

## 안내

- 스팀 게임 언어를 **영어(English)** 로 설정해야 적용됩니다.
- 스팀판 전용입니다. PS4 등 콘솔판에서는 사용할 수 없습니다.
- 게임 원본 파일은 바꾸지 않고, 게임 폴더에 파일을 추가하는 방식입니다.
- 설치 전에 세이브 파일을 백업해 두시길 권장합니다.
- 오역이나 버그 제보는 블로그 댓글로 남겨 주세요.

## 추가 기능: 실시간 컷신 60프레임

이 패치를 적용하면 **그래픽 설정 → 프레임 레이트**가 **60 FPS**일 때 실시간 컷신도 60 FPS로 부드럽게 재생됩니다.
- 미리 만들어진 동영상(무비)은 원본 영상 그대로라 달라지지 않습니다.
- 프레임 레이트가 30 FPS이면 원래 게임과 똑같이 재생됩니다.
- 컷신의 속도·음성 싱크·멈춤 같은 문제가 보이면 블로그 댓글로 제보해 주세요.
